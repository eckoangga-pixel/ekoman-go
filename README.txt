PETUALANGAN NUSANTARA — GAME EDUKASI 2.5D

CARA MENJALANKAN
1. Ekstrak ZIP ke satu folder.
2. Buka index.html menggunakan Chrome, Edge, atau Firefox terbaru.
3. Untuk suara, tekan tombol Suara ON jika browser meminta interaksi.

KONTROL
Laptop/PC: A-D atau panah kiri/kanan untuk bergerak, Spasi/↑ untuk lompat, Shift untuk lari, J untuk menembak, K untuk serangan dekat. Klik/geser pada arena untuk mengarahkan bidikan dan menembak.
HP/tablet/papan interaktif: gunakan tombol layar untuk bergerak, lompat, serang, dan tembak. Sentuh/geser arena untuk membidik.

FITUR
- Mode Solo, Duo, Squad; tingkat Mudah, Sedang, Sulit.
- Kelas 1–6 SD dan 10 mata pelajaran.
- 10 soal acak dari bank 10 soal berbeda per mata pelajaran; soal muncul setelah musuh dikalahkan.
- Nyawa, skor, bintang, jeda, kembali ke menu, efek suara sintetis, latar berganti sesuai progres.
- Aset hero, musuh, dan latar yang disediakan disertakan dalam folder assets.

CATATAN PENGEMBANGAN
Ini adalah prototipe game 2.5D berbasis Canvas (bukan mesin 3D penuh). Materi soal merupakan contoh latihan umum yang disusun untuk rentang kelas SD; sebelum digunakan sebagai asesmen resmi, guru sebaiknya meninjau dan menyesuaikan dengan CP/ATP, modul ajar, serta konteks kurikulum sekolah yang berlaku. Mode Duo/Squad saat ini berupa variasi tim/nyawa dalam satu perangkat, bukan multiplayer jaringan.

PEMBARUAN AUDIO & PAPAN INTERAKTIF DIGITAL
- Musik heroik orisinal dibuat dengan Web Audio API, bukan lagu film/game berhak cipta.
- Efek suara untuk tembakan, lompat, serangan, terkena serangan, jawaban, dan kemenangan.
- Kontrol besar selalu tampil: kiri, kanan, lompat, lari, serang, tembak.
- Di layar sentuh, geser ke kiri/kanan untuk bergerak dan geser ke atas untuk melompat.
- Browser memerlukan interaksi pertama (ketuk/klik) sebelum audio diputar.
